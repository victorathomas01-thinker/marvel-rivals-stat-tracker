# Power BI development rounds

| Round | Scope | Acceptance |
| --- | --- | --- |
| 1 — complete | Desktop setup, synthetic export, metric contract | Dataset regenerates and loads through the existing export validator; Desktop installed and opened |
| 2 — complete | SQL and Power Query preparation | SQL tables reconcile with extension; typed Power Query adapter imported successfully in Desktop |
| 3 — complete | Relationships and DAX | Six tables, three relationships, sixteen measures; native DAX acceptance query verifies totals, filters, and twelve heroes |
| 4 — built | Accessible report pages | Three native pages render with labels, exact values, hero/date controls, contrast and tab-order metadata; complete keyboard-only/screen-reader audit remains a release check |
| 5 | Portfolio delivery | Local report, source project where supported, previews, and two-minute walkthrough |

The report source will live with this case study. Publish synthetic data and reproducible transformation code. Keep local caches, credentials, and personal exports outside tracked files.

Use Power BI Desktop for the native report. Installation status and the official Microsoft installer are checked during Round 1. Authentication, administrator approval, or license acceptance may require the owner.
